SIGIL - Memetic Layer Protocol Backend System Summary

  System Overview

  SIGIL (Memetic Layer Protocol API) is a crypto prediction platform that
  enables users to make token price calls/predictions on the Farcaster
  social protocol. It operates as a hybrid blockchain-database architecture
   combining the immutability of blockchain with database performance for
  real-time operations.

  Architecture

  Technology Stack

  - Backend: NestJS (Node.js) with TypeScript
  - Database: MySQL with TypeORM
  - Blockchain: Base mainnet smart contract integration
  - Security: CSRF protection, helmet, CORS
  - API: RESTful with Swagger documentation
  - Authentication: Cookie-based with Farcaster integration

  Core Components

  1. Smart Contract Integration (ProjectLighthouseV3)

  - Contract Address: 0xdeB0E09366048944aC9033d5517Bf4Dcc39f2C97 (Base
  mainnet)
  - Functions: Signal creation, settlement, user stats, MFS scoring
  - Events: Real-time sync via event listeners
  - Settlement: Automated batch processing of expired predictions

  2. Database Models

  - User: Farcaster users with stats, MFS scores, win rates
  - Call: Prediction records with P&L tracking
  - NotificationQueue: Push notification management

  3. Core Services

  Signal/Call Management:
  - Create price predictions (up/down) for tokens
  - Track timeframes: 24h, 7d, 30d
  - Auto-settlement with price feeds
  - P&L calculation and user scoring

  User Management:
  - Farcaster identity integration
  - Performance tracking and leaderboards
  - Ban/role management system

  Blockchain Service:
  - Real-time event listening
  - Periodic blockchain-to-database sync
  - Batch settlement operations
  - Price feed integration (CoinGecko)

  Token Price Service:
  - Real-time price fetching
  - Caching layer for performance
  - Multi-token batch queries

  Key Features

  Prediction System

  - Users make "calls" predicting token price direction
  - Support for 24h, 7d, 30d timeframes
  - Automatic settlement using real market prices
  - Immutable on-chain record keeping

  Scoring & Leaderboard

  - MFS (Memetic Footprint Score): Sophisticated scoring algorithm
    - Win rate (40% weight)
    - Consistency (20% weight)
    - Recent performance (30% weight)
    - Risk-adjusted returns (10% weight)
  - Real-time leaderboard rankings
  - Minimum 5 settled calls to qualify

  Social Integration

  - Built on Farcaster protocol
  - User profiles with avatars and verification status
  - Social feeds of predictions
  - Notification system for settlements

  Data Flow

  1. Signal Creation: Frontend → Smart Contract → Event → Database Sync
  2. Auto-Settlement: Cron Jobs → Price Feeds → Batch Settlement → Database
   Update
  3. Real-time Updates: Contract Events → Service Listeners → Database →
  API

  API Structure

  Main Endpoints:

  - Signal Service: /signal-service/* - Create/manage predictions
  - User Service: /users-service/* - User profiles and stats
  - Leaderboard: /leaderboard-service - Rankings and performance
  - Token Service: /tokens-service/* - Price data and metadata
  - Admin Service: /admin-service/* - Management tools

  Key Data Models:

  // Signal/Call with blockchain integration
  interface SignalCall {
    id: string;
    fid: number; // Farcaster ID
    tokenAddress: string;
    direction: "up" | "down";
    timeframe: "24h" | "7d" | "30d";
    status: "active" | "won" | "lost" | "expired";
    pnlPercentage: number;
    txHash: string; // Blockchain transaction
  }

  // User with social features
  interface UserStats {
    fid: number;
    username: string;
    mfsScore: number; // 0-1000 scale
    winRate: number;
    totalCalls: number;
    rank: number;
  }

  Automation & Scheduling

  Background Jobs:

  - Every 5 min: Settle expired signals on blockchain
  - Every 10 min: Fallback database settlement
  - Every hour: Sync blockchain to database
  - Every 30 min: Clean price cache

  Event Processing:

  - Real-time blockchain event listeners
  - Automatic user stat recalculation
  - MFS score updates on settlements

  Security & Production Features

  Security:

  - CSRF protection with token validation
  - Helmet security headers
  - IP logging middleware
  - Admin role-based access control
  - SSL database connections

  Performance:

  - Connection pooling (10 connections)
  - Price caching (5-minute intervals)
  - Batch blockchain operations
  - Pagination for large datasets

  Use Cases & Business Logic

  Primary Use Case:

  Platform for crypto prediction competitions where users make public token
   price calls, compete on leaderboards, and build reputation through
  accurate predictions.

  Target Users:

  - Crypto traders and analysts
  - Farcaster community members
  - Social prediction enthusiasts
  - DeFi participants

  Monetization Potential:

  - Premium features
  - Prediction staking mechanisms
  - Social tipping integration
  - Analytics subscriptions

  This system combines social media engagement with DeFi prediction 
  markets, leveraging blockchain immutability while maintaining traditional
   database performance for a compelling user experience.
